Підготовка

Стартовий скрипт: таблиця students

Це таблиця з практичної 01. Скопіюйте скрипт у PlayCode — увесь сьогоднішній код пишіть нижче, у тому самому вікні.

стартовий скрипт 
DROP TABLE IF EXISTS students;

CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    full_name TEXT NOT NULL,
    group_name TEXT NOT NULL,
    email TEXT UNIQUE,
    achievements TEXT,
    votes INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    registered_at DATE NOT NULL
);

Як працювати зі скриптом

  • 🔁 Кожен запуск — з нуля. PlayCode виконує весь код зверху вниз: таблиця створюється заново і заповнюється вашими INSERT. Тому записи не дублюються, скільки б разів ви не запускали.
  • 📋 Результат запиту SELECT з'являється у вкладці Results, помилки — у Console.
  • 💬 Кілька запитів. Якщо в Results видно лише останній, тимчасово закоментуйте інші: -- на початку рядка.
Додавання даних

Команда INSERT INTO

Додає нові рядки в таблицю. Це як заповнити анкету: називаємо поля і вписуємо в них значення.

Шаблон і приклад 
-- Шаблон
INSERT INTO таблиця (колонка_1, колонка_2)
VALUES (значення_1, значення_2);

-- Два студенти одним запитом
INSERT INTO students (full_name, group_name, registered_at)
VALUES
    ('Софія Ткаченко', 'Б-21', '2026-09-03'),
    ('Максим Шевчук', 'М-21', '2026-09-03');

Правила

  • 1 Порядок значень = порядок колонок у дужках. Кількість теж має збігатися.
  • 2 id не вказуємо — SERIAL пронумерує рядки сам.
  • 3 Колонки, яких немає в списку, отримають DEFAULT (votes → 0, is_active → TRUE) або залишаться порожніми — NULL.
  • 4 Кілька рядків — через кому, крапка з комою ; — лише в кінці.
  • 5 NULL означає «значення немає». Пишеться без лапок.
Вибірка даних

Команда SELECT

Показує дані з таблиці. SELECT нічого не змінює — лише «фотографує» потрібну частину таблиці.

Приклади 
-- Усі колонки, усі рядки
SELECT * FROM students;

-- Лише потрібні колонки
SELECT full_name, group_name, votes
FROM students;
  • SEL SELECT — які колонки показати. * означає «усі».
  • FR FROM — з якої таблиці брати дані.
Результат другого запиту
full_name group_name votes
Олександр КоваленкоМ-2112
Анастасія МельникБ-119
Дмитро БондаренкоМ-325

💡 Колонки йдуть у тому порядку, у якому ви їх перелічили. Інших колонок (email, дата…) у результаті немає, але в таблиці вони нікуди не зникли.

Фільтрація

Умова WHERE

WHERE — це фільтр: у результат потрапляють лише ті рядки, для яких умова виконується.

Оператор Приклад умови Що означає
=group_name = 'М-21'дорівнює
<>group_name <> 'М-21'не дорівнює
> <votes > 10більше / менше
>= <=votes >= 10більше або дорівнює…
ANDvotes > 5 AND is_active = TRUEобидві умови разом
ORgroup_name = 'М-21' OR group_name = 'Б-11'хоча б одна з умов
NOTNOT is_activeзаперечення («не активний»)
Приклад 
-- Студенти групи М-21, у яких більше 5 голосів
SELECT full_name, votes
FROM students
WHERE group_name = 'М-21' AND votes > 5;
Текст порівнюється з урахуванням регістру: 'м-21' і 'М-21' — різні значення. Запит з малою «м» поверне 0 рядків без жодної помилки.
Фільтрація

Особливі умови: LIKE, IN, BETWEEN, IS NULL

Для пошуку за частиною тексту, за списком значень, у проміжку та серед порожніх полів.

Умова Приклад Що знайде
LIKE full_name LIKE '%енко' ПІБ, що закінчується на «енко». % — будь-які символи
IN group_name IN ('М-21', 'Б-11') значення з переліченого списку
BETWEEN registered_at BETWEEN '2026-09-01' AND '2026-09-07' значення в проміжку, включно з межами
IS NULL achievements IS NULL порожні поля (значення немає)
IS NOT NULL achievements IS NOT NULL заповнені поля
Пастка: achievements = NULL не працює. Помилки не буде, але запит завжди поверне 0 рядків. Для порожніх значень пишіть лише IS NULL.
Живий зразок коду

Зразок: додаємо студентів і шукаємо

Вставте під стартовим скриптом і запустіть. Потім спробуйте змінити умови й подивіться, як змінюється результат.

демо-скрипт (після стартового) 
-- Додаємо трьох студентів (is_active не вказуємо — спрацює DEFAULT TRUE)
INSERT INTO students (full_name, group_name, email, achievements, votes, registered_at)
VALUES
    ('Олександр Коваленко', 'М-21', 'kovalenko@college.ua', 'Переможець олімпіади з фізики', 12, '2026-09-01'),
    ('Анастасія Мельник', 'Б-11', 'melnyk@college.ua', 'Волонтерка', 9, '2026-09-01'),
    ('Дмитро Бондаренко', 'М-32', 'bondarenko@college.ua', NULL, 5, '2026-09-02');

-- Хто з групи М-21?
SELECT full_name, votes FROM students WHERE group_name = 'М-21';

-- У кого більше 8 голосів?
SELECT full_name, group_name, votes FROM students WHERE votes > 8;

🔍 Перший запит знайде лише Олександра Коваленка, другий — Коваленка (12) і Мельник (9).

Помилки при вставці та пошуку даних. Текст помилки шукайте у вкладці Console.

Повідомлення PostgreSQL Що сталося Як виправити

Тиха пастка з датою: '01.09.2026' PostgreSQL прийме без помилки, але збереже як 9 січня (2026-01-09). Завжди пишіть дати у форматі 'РРРР-ММ-ДД'.
Практичне завдання Студент тижня

Наповніть таблицю і знайдіть потрібних студентів

Пишіть код під стартовим скриптом. Демо-код зі слайду 7 у звіт не додавайте.

Крок 1 • INSERT 🏆 Студент тижня

Додайте щонайменше 6 студентів

  • Себе та одногрупників (дані можна вигадати).
  • Щонайменше 2 різні групи.
  • Один студент з is_active = FALSE.
  • У двох студентів не заповнюйте achievements.
  • Різна кількість голосів votes — від 0 до 20.
  • Дати реєстрації — у форматі 'РРРР-ММ-ДД', наприклад '2026-09-05'.
Крок 2 • SELECT

Напишіть 5 запитів

  1. Усі дані таблиці.
  2. Лише ПІБ, група і кількість голосів усіх студентів.
  3. Усі студенти вашої групи.
  4. Активні студенти, у яких більше 5 голосів (AND).
  5. Студенти, у яких не заповнені досягнення (IS NULL).
Перевірте себе: запит 1 показує всі ваші рядки, у запиті 4 немає неактивного студента, запит 5 знаходить рівно двох.
Контрольні запитання

Контрольні запитання та висновок

Дайте письмові відповіді на 5 запитань і зробіть короткий висновок. Можна від руки (фото) або у файлі .docx.

5 запитань
  1. Що робить команда INSERT INTO? Що станеться з колонками, які ви не вказали в запиті?
  2. Чим відрізняється SELECT * від SELECT full_name, votes?
  3. Для чого потрібна умова WHERE? Наведіть приклад з вашої таблиці.
  4. Чим відрізняються оператори AND і OR?
  5. Чому порожні значення шукають через IS NULL, а не через = NULL?
