Агрегатні функції

COUNT, SUM, AVG, MIN, MAX

Агрегатна функція «згортає» багато рядків в одне число — як підсумковий рядок у кошторисі.

Функція Що рахує Результат*
COUNT(*)кількість рядків8
COUNT(achievements)лише заповнені значення (без NULL)6
SUM(votes)суму62
AVG(votes)середнє значення7.7500000000000000
ROUND(AVG(votes), 1)середнє, округлене до 1 знака7.8
MIN(votes) / MAX(votes)найменше / найбільше0 / 15

* на даних стартового скрипту, таблиця students

Приклад 
SELECT COUNT(*) AS total_students,
       SUM(votes) AS total_votes
FROM students;
AS дає колонці результату зрозумілу назву. Без нього колонки називались би просто count і sum. Результат цього запиту — один рядок: 8 | 62.
Групування

GROUP BY: підсумки по групах

Уявіть, що ви розклали картки студентів у купки за групою, а потім порахували кожну купку окремо.

Найкращий результат у кожній групі 
SELECT group_name, MAX(votes) AS best
FROM students
GROUP BY group_name
ORDER BY group_name;
group_namebest
Б-119
Б-2115
М-2112
М-3211

Як це працює

  • 1 СУБД ділить рядки на групи з однаковим значенням group_name.
  • 2 Агрегатна функція рахується окремо для кожної групи.
  • 3 У результаті — один рядок на групу: 8 студентів → 4 рядки.
Правило: кожна колонка в SELECT має бути або в GROUP BY, або всередині агрегатної функції.
Фільтрація груп

HAVING і порядок частин запиту

WHERE відсіює рядки до групування, HAVING — цілі групи після підрахунку.

Групи, де щонайменше 2 активні учасники 
SELECT group_name, COUNT(*) AS students_count
FROM students
WHERE is_active = TRUE        -- фільтр рядків
GROUP BY group_name
HAVING COUNT(*) >= 2;      -- фільтр груп

Результат: Б-21, М-21 і М-32 — по 2 активні учасники. Групи Б-11 немає: Вікторія Лисенко неактивна, тож там лишився один учасник.

Порядок частин запиту

  1. SELECT — що показати
  2. FROM / JOIN — звідки
  3. WHERE — які рядки взяти
  4. GROUP BY — як згрупувати
  5. HAVING — які групи залишити
  6. ORDER BY — як відсортувати
  7. LIMIT — скільки показати

💡 Будь-яку частину, крім SELECT і FROM, можна пропустити, але порядок змінювати не можна.

Агрегація + JOIN

Рахуємо голоси з журналу

Найчесніший підрахунок — не лічильник votes, а кількість рядків у журналі student_votes.

Голоси з журналу по групах 
SELECT students.group_name,
       COUNT(student_votes.id) AS real_votes
FROM students
LEFT JOIN student_votes
    ON students.id = student_votes.student_id
GROUP BY students.group_name
ORDER BY real_votes DESC;
group_namereal_votes
Б-216
М-215
М-323
Б-112

На що звернути увагу

  • 1 Спершу JOIN «склеює» студентів з їхніми голосами, потім GROUP BY групує, а COUNT рахує.
  • 2 COUNT(student_votes.id), а не COUNT(*): для студента без голосів LEFT JOIN дає рядок з NULL, і COUNT(*) порахував би його як 1 голос.
  • 3 Колонки з назвами таблиць (students.group_name), бо запит працює з двома таблицями.
Живий зразок коду

Зразок: активність голосування по днях

У які дні голосували найактивніше? Вставте під стартовим скриптом і запустіть.

демо-скрипт (після стартового) 
-- Скільки голосів віддали кожного дня
SELECT voted_at, COUNT(*) AS votes_count
FROM student_votes
GROUP BY voted_at
ORDER BY voted_at;

-- Лише «гарячі» дні: 4 голоси і більше
SELECT voted_at, COUNT(*) AS votes_count
FROM student_votes
GROUP BY voted_at
HAVING COUNT(*) >= 4;

🔍 Перший запит — 5 днів: 3, 4, 4, 3 і 2 голоси. Другий — лише 9 і 10 вересня (по 4 голоси).

Помилки та пастки

Перша помилка в списку — найчастіша в усій темі агрегації.

Повідомлення PostgreSQL Що сталося Як виправити
column "students.full_name" must appear in the GROUP BY clause or be used in an aggregate function Колонка в SELECT не згрупована Додайте її в GROUP BY або приберіть з SELECT
aggregate functions are not allowed in WHERE SUM / COUNT у WHERE Умову на підсумок пишіть у HAVING
column "total" does not exist Назву з AS використали в HAVING Повторіть вираз: HAVING SUM(votes) > 15
syntax error at or near "GROUP" HAVING написано перед GROUP BY Порядок: GROUP BY … HAVING …
function cont() does not exist Описка в назві функції Перевірте: COUNT, SUM, AVG…
Тиха пастка: SUM(votes) / COUNT(*) дасть 7, а не 7.75 — ділення цілих чисел відкидає дробову частину. Для середнього використовуйте AVG, а для гарного вигляду — ROUND(AVG(votes), 1).

Аналітика конкурсу і переможець

Пишіть запити під стартовим скриптом. Кожну колонку результату назвіть через AS.

Завдання 🏆 Студент тижня
  1. Скільки активних учасників у конкурсі.
  2. Одним запитом: загальна, середня (округлена до 1 знака) і максимальна кількість голосів з колонки votes.
  3. Для кожної групи: кількість студентів і сума голосів. Група з найбільшою сумою — вгорі.
  4. Лише групи, де сума голосів більша за 15 (HAVING).
  5. Студент тижня: порахуйте голоси кожного студента з журналу student_votes і виведіть переможця — один рядок: ПІБ, група, кількість голосів.

Підказки

  • Запит 1 — COUNT + WHERE.
  • Запит 3 — GROUP BY + ORDER BY … DESC.
  • Запит 5 — JOIN + GROUP BY за id, ПІБ і групою + ORDER BY + LIMIT 1.
Перевірте себе: запит 1 → 7; запит 2 → 62, 7.8, 15; запит 3 → М-21 вгорі (19 голосів); запит 4 → 3 групи; запит 5 → Софія Ткаченко, Б-21, 5 голосів.
