Сортування

ORDER BY і LIMIT: рейтинг та топ-3

Саме так головна сторінка «Студента тижня» будує лідерборд: сортує за голосами і показує кількох перших.

Приклад 
-- Трійка лідерів за голосами
SELECT full_name, votes
FROM students
ORDER BY votes DESC
LIMIT 3;
full_namevotes
Софія Ткаченко15
Олександр Коваленко12
Андрій Кравченко11

Як це працює

  • ASC За зростанням (1, 2, 3… або А → Я). Діє за замовчуванням, тож ASC можна не писати.
  • DESC За спаданням (від більшого до меншого, Я → А).
  • 1, 2 Кілька колонок: ORDER BY votes DESC, full_name — спершу за голосами, а при однаковій кількості — за ПІБ за абеткою.
  • LIM LIMIT n — показати лише перші n рядків. Пишеться в самому кінці, після ORDER BY.
Зміна даних

Команда UPDATE

Змінює значення в уже наявних рядках. Кнопка «Проголосувати (+1)» зі вступної лекції виконує саме такий запит.

Приклади 
-- Голос «+1» для студентки з id = 4
UPDATE students
SET votes = votes + 1
WHERE id = 4;

-- Кілька колонок одним запитом
UPDATE students
SET achievements = 'Повернулася до конкурсу',
    is_active = TRUE
WHERE id = 6;
  • UPD UPDATE — яку таблицю змінюємо.
  • SET SET — що на що замінити. votes = votes + 1 означає «візьми поточне значення і додай 1». Кілька колонок — через кому.
  • WH WHERE — які саме рядки змінити. Найнадійніше — за id.
UPDATE без WHERE змінить кожен рядок таблиці — і СУБД не видасть жодної помилки. Наприклад, UPDATE students SET votes = 0; обнулить голоси всім.
Видалення даних

Команда DELETE

Видаляє рядки з таблиці. Сама таблиця і її структура залишаються. Кнопки «Скасувати» в SQL немає.

Золоте правило в дії 
-- 1. Спочатку дивимося, кого зачепить умова
SELECT * FROM students WHERE is_active = FALSE;

-- 2. Переконалися — видаляємо з ТІЄЮ САМОЮ умовою
DELETE FROM students WHERE is_active = FALSE;
КомандаЩо видаляє
DELETE FROM … WHERE …лише рядки, що підходять під умову
DELETE FROM students;усі рядки, таблиця стає порожньою
DROP TABLE students;таблицю повністю: і дані, і структуру
Золоте правило: перед кожним UPDATE чи DELETE виконайте SELECT з тим самим WHERE. Побачили потрібні рядки — тоді змінюйте.
Живий зразок коду

Зразок: сортуємо, голосуємо, видаляємо

Вставте під стартовим скриптом і запустіть. Запити виконуються по черзі, зверху вниз.

демо-скрипт (після стартового) 
-- Список учасників за абеткою
SELECT full_name, group_name FROM students ORDER BY full_name;

-- Двоє найновіших учасників
SELECT full_name, registered_at FROM students ORDER BY registered_at DESC LIMIT 2;

-- Голос «+1» для Дмитра Бондаренка (id = 3) і перевірка
UPDATE students SET votes = votes + 1 WHERE id = 3;
SELECT id, full_name, votes FROM students WHERE id = 3;

-- Вікторія Лисенко (id = 6) вибула з конкурсу
DELETE FROM students WHERE id = 6;

Типові помилки

Помилки та пастки

Найнебезпечніші помилки в цій темі — ті, про які СУБД не попереджає.

Повідомлення PostgreSQL Що сталося Як виправити
syntax error at or near "ORDER" LIMIT написано перед ORDER BY Правильний порядок: ORDER BY … LIMIT …
syntax error at or near "*" DELETE * FROM — звичка з SELECT DELETE FROM students WHERE …
syntax error at or near "WHERE" Зайва кома перед WHERE в UPDATE Кома — лише між колонками в SET
column "vote" does not exist Описка в назві колонки Перевірте назву: votes
Помилки немає, але нічого не змінилося WHERE не знайшов жодного рядка (напр. id = 999) Перевірте умову через SELECT
Головна пастка: UPDATE або DELETE без WHERE виконується без жодної помилки — і змінює або видаляє усі рядки.
